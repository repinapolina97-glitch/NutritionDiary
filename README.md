 🥗 Дневник питания
 Веб-приложение для учёта БЖУ и питания. Один HTML-файл, работает без интернета и установки.

 Функционал:
- Добавление продуктов: название, ккал, белки, жиры, углеводы
- База из 30 популярных продуктов (значения на 100 г)
- Разделение по приёмам пищи: завтрак, обед, ужин, перекус
- Автоматический подсчёт итогов за день
- Настраиваемые дневные нормы
- Прогресс-бары по калориям, белкам, жирам, углеводам
- Счётчик воды (8 стаканов)
- Переключение между днями (вчера / сегодня / завтра)
- Сохранение данных в LocalStorage
- Экспорт дня в CSV (открывается в Excel)
- Проверка ввода и защита от HTML-инъекций

Как запустить:
1. Сохранить код как `nutrition.html` в Блокноте (тип файла — «Все файлы»)
2. Открыть двойным кликом в браузере

Технологии
HTML + CSS + JavaScript (Vanilla). Без библиотек и CDN.
